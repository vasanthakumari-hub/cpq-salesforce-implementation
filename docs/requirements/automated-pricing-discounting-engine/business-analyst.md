# Automated Pricing & Discounting Engine — Business Analyst

User Story: As a Sales Operations Manager, I want to automate pricing adjustments based on volume and margins so that we maintain profitability without manual calculations.
Acceptance Criteria: 
1. Price Rules must inject values into Quote Line fields (e.g., Target Price, Floor Price).
2. Discount Schedules must be linked to Products for tiered/volume pricing.
3. Multi-currency price books must be active.
4. If logic exceeds declarative limits, a Quote Calculator Plugin (QCP) must be implemented.
