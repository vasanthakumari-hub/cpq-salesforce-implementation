# CPQ Product Catalog & Bundle Configuration — Business Analyst

User Story: As a Sales Rep, I want to select pre-defined product bundles so that I can ensure all required components and accessories are included accurately in a quote.
Acceptance Criteria: 
1. CPQ Product Bundles must be configured with Parent-Child hierarchies.
2. Product Options must be grouped by 'Features' within the QLE.
3. Selection rules must prevent incompatible product combinations.
4. Summary variables must be used to calculate aggregate totals for product rule logic.
