# Security & Access Control for Pricing Data — Business Analyst

User Story: As a Sales VP, I want to ensure that pricing fields like 'Floor Price' are restricted to specific users so that sensitive margin data is protected.
Acceptance Criteria: 
1. Permission Sets must be created for Sales Reps (Read Only for Margin).
2. Permission Sets must be created for Sales Ops/Finance (Edit access for Pricing Logic).
3. Field Level Security (FLS) must be enforced on sensitive CPQ fields.
